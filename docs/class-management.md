# 学校管理者のクラス管理

この開発環境は1校を対象とします。ADMINはこの環境の全クラス・教員・生徒を扱えます。複数校共用への対応・学校別管理者・複数クラスの兼任は含みません。

## 操作

管理者でログインすると `/admin/classes` に移動します。

- 年度・学年・クラス名を入力し、確認画面で保存するとクラスを新規作成します。同名の別クラスも作成できるため、登録済み一覧を確認してください。
- クラスの「編集」は名称・年度・学年の修正です。ID、授業進度、所属は変えません。進級時に旧クラスの名称だけを書き換えると過去のクラスを再利用することになります。新年度のクラスは新規作成して所属を変更してください。
- 教員・生徒を選び、変更先クラスを指定し、変更前後を確認して保存します。1人ずつの変更です。教員の担当変更で生徒は自動移動しません。
- 学習記録・先生が登録した理解度・AI設定・保護者/支援者の紐づけはユーザーIDに紐づくため維持します。移動先の教員はその生徒の過去の学習記録も閲覧できます。移動前の教員はAPIで拒否されます。生徒の学校進度は移動先のクラスの情報になります。既存プランの自動再生成はしません。
- 招待履歴のclass_idは招待時の所属として保持します。所属変更後は旧教員の招待一覧から対象生徒と関連する保護者/支援者の招待が隠れます。招待の再送による所属変更はできません。初回パスワード設定済みの利用者は自分のメールアドレスと既存パスワードで引き続きログインします。
- クラス・ユーザーの削除、管理者の招待・昇格、CSV一括処理はこの画面にはありません。

## 権限と履歴

ADMINはCognitoグループとUsers.roleの両方に登録します。一般教員の招待APIではADMINを指定できません。クラス管理APIにもCognito認証が必要です。DB上で現在の権限を確認し、保存トランザクション内で再確認します。

`ClassAudit` に変更者、日時、操作、対象ID、変更前後を保存します。所属・クラスの変更と履歴は同一トランザクションで確定します。同時編集と、いったん移動して元のクラスに戻った後の古い画面からの保存もバージョンチェックで拒否します。履歴は新しい100件を表示します。履歴には氏名とクラス情報が含まれます。

クラスとユーザーの一覧・履歴は全ページを取得するScanを使っています。小規模なデモ向けです。人数や履歴が増える実運用ではインデックスとページングを追加してください。履歴テーブルは既存と同様の開発用DESTROYポリシーのため、DataStackをdestroyすると履歴も削除されます。

## 反映

1. バックエンドテスト、フロントテスト/lint/build、インフラbuild/testを実行します。
2. `StudyPlatformApiStack` のdiffを確認しデプロイします。依存するDataStackにはClassAuditテーブル、AuthStackにはADMINグループが追加されます。既存のユーザープールを置換しません。
3. フロントをbuild後、StudyPlatformFrontendStackをdiff・デプロイします。
4. 最初の管理者は、AWS権限のある運用者が下記スクリプトで新しい専用メールアドレスを登録します。既存の教員を昇格させません。

```powershell
.\backend\.venv\Scripts\python.exe .\backend\scripts\create_school_admin.py --email "受信できる未登録のメールアドレス" --name "学校管理者"
```

上記は確認のみです。同じ引数に `--create` を追加するとアカウントを作成してCognitoの招待メールを送信します。メール内の仮パスワードで公開サイトにログインし、本人のパスワードを設定します。AWS認証にlogin providerを使う環境では `pip install "botocore[crt]"` が必要です。

途中で作成やメール送信が失敗した場合、既存メールを再実行しても自動変更しません。既存アカウントを保護するため停止します。AWS運用者がCognitoの属性・ADMINグループ・Usersの紐づけを確認し、必要な場合だけ招待を再送します。画面から新たな管理者を作成することはできません。

## 実環境での確認

- 新管理者の初回パスワード設定、管理画面への遷移。
- 新クラスの作成と名称変更、履歴の表示。
- テスト生徒を新クラスへ移動し、旧担当教員からの閲覧拒否、新担当からの閲覧、過去記録と保護者の紐づけの維持。
- 保存前に別ウィンドウから所属を変更し、古いフォームの保存が拒否されること。
- 一般教員の `/admin/classes` アクセス拒否。

ローカルのAPIテストはMoto、画面テストは通信スタブで行います。実際のアカウント作成・メール到達・AWS上の所属変更はデプロイ後に確認してください。
