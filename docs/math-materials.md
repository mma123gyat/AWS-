# 数学教材の組み込み

自作教材 `junior-high-study-app 1.zip` の数学55単元を、生徒ポータルの「数学教材」に移植しています。他の4教科の教材、元アプリのログイン・ユーザー名入力・コイン・固定の習熟スコア・段階ロックは移植していません。

## 利用方法

- 生徒のメニュー「数学教材」から55単元を探し、解説・図の操作・確認問題・基礎／標準／発展の演習に取り組めます。
- 今日の課題の教科IDが `math` で、単元名が対応表に一致する場合、課題カードに教材へのリンクを表示します。例：比例、反比例、比例・反比例、一次方程式。
- 自由入力の単元名から推測して誤った教材を開くことを避けるため、一致する教材がない課題にはリンクを出しません。追加の対応表は `mathMaterials.ts` の `UNIT_ALIASES` で管理します。
- 今日の課題から開いた場合は、ページ下部で学習時間と本人の理解度1〜5を保存できます。既存の `POST /study-records` を利用するため、同じ課題の完了記録は重複計上しません。
- 比例・反比例のように1つの課題に教材が複数ある場合も、課題の学習時間をまとめて一度記録します。全問正解を保存条件にはしていません。
- 一覧からの自由練習は閲覧・演習のみです。自由練習の学習ログ保存、途中解答の永続化、回答・ヒント履歴の保存は今回の対象外です。正答率を本人の理解度や教員の評価へ自動変換しません。

## データと修正

- 数学のみ55単元、確認55問＋演習165問＝220問。教材とCanvasは必要な画面で遅延読み込みします。
- 選択肢は問題の表示時に並べ替えます。選択肢IDと正解の対応を維持し、再描画で順番が変わらないようにしています。
- 正解後の確認ボタンを無効化し、元アプリの繰り返し加点・コイン処理は使用しません。
- Step32の平方根の定義・「根号を使わず」の矛盾、Step54の平方和の問題文を修正しました。
- 教材内容の全問専門校閲は未実施です。公開・授業利用前に教員等による確認を行ってください。特定の出版社の公式教材・公認教材であるとは表示していません。
- 解答はブラウザで確認できる練習用です。正式な試験・成績評価に利用する場合は、サーバー側での出題・採点・回答履歴管理を別途設計してください。

## 変更範囲

フロントエンドのみ。追加のAWSリソース、API、認証方式、AI生成処理、教員・保護者・支援者の集計処理には変更を加えていません。生徒用の既存ロールガード内に画面を追加しています。

## 手動で確認する項目

1. 生徒でログインし、数学教材に55単元あること。スマートフォン幅でも選択肢と図が表示されること。
2. 教員画面で生徒の数学の現在地を「比例・反比例」に設定し、学校側の数学進度も登録する。既存仕様に従って数学が選ばれる状態で新規プランを作成する。
3. 今日の数学課題に比例／反比例へのリンクが表示され、各教材を開けること。
4. 学習時間5分・理解度4などを保存し、ページの再読み込み後に保存済みとして表示されること。
5. 教員の学習ログ、学習時間の集計に、課題の完了が1件だけ反映されること。
6. 他教科・対応しない単元の課題に誤った数学リンクが出ないこと。教材URLの課題ID・単元番号を変えても、不一致の課題の記録フォームが出ないこと。

ローカルのビルド・自動テストは実行していますが、AWS実環境への適用・デプロイ・実ユーザーでの確認は行っていません。
