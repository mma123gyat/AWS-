# 数学の単元選択

教員画面の「学校の授業の現在地」「生徒の学習の現在地」で、数学を選ぶと55単元の教材一覧を学年別に表示する。一覧から選んだ正式な単元名を、既存のAPIで保存する。

- 生徒の現在地の単元名が教材に対応すると、今後新しく生成する数学課題に教材リンクが付く。学校進度だけの変更でリンクが付くわけではない。
- 国語・理科・社会・英語は従来の手入力。
- 既存の「比例・反比例」等の別名や、教材一覧にない単元は「現在の入力」として保持し、自動で置き換えない。
- 「一覧にない単元を入力する」で数学も手入力できる。教材対応の有無を表示する。
- 教材一覧と手入力を切り替えるだけでは単元名を変更しない。一覧の単元を選ぶか文字を入力したときだけ、その教科の下書きが変わる。
- 教科の切り替えで下書きを保持する既存処理、再読み込み時の確認、保存・権限チェックは維持する。
- 作成済みのプラン・学習記録は変更しない。同日の生成済み教科・時間へ戻る場合も元のプランを再利用する。

フロントのみの変更。バックエンド、API形式、テーブル、インフラ変更は不要。
