# 生徒による教科選択

数学教材パッチ適用後の追加変更。学習時間の画面で、教員が生徒の現在地を登録した教科から「今日学ぶ教科」を選ぶ。

## APIと保存

- GET `/students/me/dashboard` に `availableSubjects`（`subject_id` と `unit_name` の配列）を追加。現在地の表示も選択中の教科に合わせる。
- POST `/students/me/condition` に任意の `subjectId` を追加。本人の現在地と担当クラスの学校進度が存在する場合だけ保存。休む場合は教科を保存しない。
- 古いクライアントの教科指定なしリクエストは従来どおり扱う。
- プランは教科と時間の組み合わせで再利用。既存の時間だけのキャッシュは、そのプランの教科が一致する場合だけ明示選択に使う。
- プラン生成・復元と課題完了のトランザクションは、教科も条件に含める。別タブで教科を変更した場合、古い課題を新たに完了させない。保存済み記録への同一内容の再送は従来どおり同じ記録を返す。
- テーブル・キー・既存データの移行作業は不要。PostConditionFn に StudentProgresses と Curriculums の読み取り権限を追加。

## 反映の順序

1. バックエンドとインフラの検証後、StudyPlatformApiStack を diff・deploy。
2. フロントを build し、ローカルで操作を確認。
3. StudyPlatformFrontendStack を diff・deploy。

フロントだけ先に反映すると、古いAPIには教科一覧がないため、教科選択での登録を止めてAPI更新を案内する。

## 数学の確認手順

1. 担当教員で、生徒の数学の現在地を登録する。教材確認用の単元名の例は「正負の数の加法・減法」。
2. その生徒の所属クラスの数学の授業進度も登録済みであることを確認する。学校進度はクラス全体に反映されるため、実際の授業の単元を使う。
3. 生徒で「学習時間」を開き、算数・数学と15分を選んで登録する。
4. ダッシュボードで「この設定の学習プランを表示する」を押す。AIの課題の単元は生徒の数学の現在地を使う。
5. 課題の教材リンクを開き、問題に取り組み、実際の時間と理解度を保存する。
6. 教科を国語に切り替え、同じ15分で別のプランが出ることを確認する。
7. 数学・15分へ戻してプランを表示し、元の課題と完了記録が残ることを確認する。

数学教材のリンクは既存の対応表に合う単元でだけ表示する。教材一覧からの自由練習は記録保存しない。問題の正誤を理解度に自動変換しない。
