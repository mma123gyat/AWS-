# 動画教材（理科・国語・英語・社会）とエンドレス演習

## スコープ

生徒ポータルに、数学以外の4教科（理科・国語・英語・社会）の学習コンテンツと、教科を問わず使えるエンドレス演習（問題ページ）を追加した。フロントエンドのみの変更で、バックエンド・API・DB・AWSリソースの変更は無い。

- 単元一覧（カタログ）→ 単元を選ぶ（ライトスピード風の演出）→ 動画＋穴埋め要約 → 「次へ」で演習問題 → 単元一覧に戻る、という流れを `frontend/src/features/videoLesson/` に実装。
- 単元選択の演出は `frontend/src/components/ui/WarpTransition.tsx`（`WarpLink`）として共通化し、既存の数学カタログ（`MathMaterialsPage.tsx`）の単元リンクにも適用した（ロジックは変更していない）。
- エンドレス演習（`frontend/src/features/videoLesson/PracticePage.tsx`、`/practice/:subject`）は、数学を含む5教科すべてで使える。教科内の全単元の演習問題からランダムに1問ずつ出題し続け、正解した数をスコアとして画面に表示する。スコアは画面を開いている間だけの値で、保存しない（ページを離れると0に戻る）。
- 教科を選ぶ最上位メニュー（`/materials`、`SubjectMenuPage.tsx`）を新設した。

## コンテンツの状態（既知の制約）

- 今回はパイロット版として、理科・英語のみ実際の動画（YouTube埋め込み）・穴埋め要約・演習問題を4単元ずつ作成した（`frontend/src/features/videoLesson/lessons.ts`）。動画は参考サイト（ponyoani.net、gakken-ep.jp）が案内しているYouTube動画を、通常のiframe埋め込みで参照している。
- 国語・社会は、参考サイト（19ch.tv）の動画がJavaScriptで描画されており、自動取得では実際のYouTube動画IDを確認できなかったため、単元名のみカタログに登録し、レッスン本体（動画・要約・演習）は未作成。該当の単元を開くと「準備中」の案内が表示される（数学の未実装単元と同じ考え方）。動画IDが分かれば `lessons.ts` に追記するだけで公開できる。
- 単元数も各教科4件のみ。残りの単元は今後、同じパターンで追加していく想定（数学が55単元中29単元を段階的に実装してきたのと同じ進め方）。

## API/バックエンド変更

なし。既存の `studentApi` や学習記録（`StudyRecord`）とは独立していて、連携もしていない。

## 手動テストチェックリスト

- [ ] 生徒でログインし、ナビゲーションの「教材」から `/materials` を開くと5教科のカードが表示される
- [ ] 教科カードをクリックすると、ワープ風の演出が約0.5秒再生されてから単元一覧に遷移する
- [ ] 理科・英語の実装済み単元をクリックすると、動画が再生でき、穴埋め要約の空欄を選んで正誤判定できる
- [ ] 全ての空欄が正解すると「次へ：演習問題」が有効になり、演習問題に進める
- [ ] 演習問題でヒント表示・正誤判定・解説表示が機能する
- [ ] 演習を終えると「単元一覧へ」で単元一覧に戻れる
- [ ] 国語・社会、または未実装単元を開くと「準備中」の案内が表示される
- [ ] 各教科の単元一覧から「ひたすら演習する」→ `/practice/:subject` に入り、正解するたびにスコアが増え、何問でも続けられる
- [ ] 「やめてメニューに戻る」で単元一覧に戻れる。ページを再読み込みするとスコアが0に戻る
- [ ] 数学の単元一覧でも同じワープ演出が動作し、既存のレッスン・演習フローに回帰がないことを確認する

## 既知の制約

- スコアはセッション内のみで、生徒・教師・保護者のどの画面にも永続化・共有されない（意図的な仕様。`docs/math-materials.md` で過去にコイン等のゲーミフィケーション要素を除外した経緯と一貫させている）。
- 国語・社会のレッスン本体は未作成（上記「コンテンツの状態」参照）。
